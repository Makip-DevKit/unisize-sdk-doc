## プライバシーマニフェストファイルについて

2024年春以降にリリースするiPhone、iPad向けアプリには、プライバシーマニフェスト対応が必須となりました。
unisizeSDKを導入する場合、アプリのプライバシーマニフェストファイル（PrivacyInfo.xcprivacy）の追加、修正を行ってください。


## unisizeSDK で使用する項目

**App Privacy Configuration > Privacy Nutrition Label Types > Item ◯**
```
Collected Data Type：Purchase History
Linked to User：YES
Used for Tracking：NO
Collection Purposes > item 0：App Functionality
Collection Purposes > item 1：Analytics
Collection Purposes > item 2：Product Personalization
```
unisize の利用・非利用集計で購入履歴を使用しています。  

**App Privacy Configuration > Privacy Nutrition Label Types > Item ◯**
```
Collected Data Type：User ID
Linked to User：YES
Used for Tracking：NO
Collection Purposes > item 0：App Functionality
Collection Purposes > item 1：Analytics
Collection Purposes > item 2：Product Personalization
```
  
unisize のログイン、サイズレコメンドでユーザーIDを使用しています。  

**App Privacy Configuration > Privacy Nutrition Label Types > Item ◯**
```
Collected Data Type：Photos or Videos
Linked to User：NO
Used for Tracking：NO
Collection Purposes > item 0：App Functionality
```
  
FacChange、AI写真採寸を利用する際に写真を使用します。  

**App Privacy Configuration > Privacy Nutrition Label Types > Item ◯**
```
Collected Data Type：Email Address
Linked to User：YES
Used for Tracking：NO
Collection Purposes > item 0：App Functionality
```
unisize のログイン、会員登録で Email Address を使用しています。  
  
**App Privacy Configuration > Privacy Nutrition Label Types > Item ◯**
```
Collected Data Type：Crash Data
Linked to User：YES
Used for Tracking：NO
Collection Purposes > item 0：Analytics
```

エラーロギング（sendErrorLog）を有効にする場合は、上記項目も追加して下さい。

* Item ◯ の「◯」には、項目を追加した際に数字が割り振られます。
* Appleの審査が通過することを保証するものではありませんので、あらかじめご了承ください。
* アプリ、アプリで使用している他の SDK で対応が必要な項目がある場合は、適切な項目を追加して下さい。項目が重複する場合、同じ項目を複数登録する必要はありません。また、アプリ、アプリで使用している他の SDK と unisizeSDK で「YES」、「NO」が異なる場合は、「YES」を優先で設定して下さい。
* Collection Purposesは複数項目の追加が可能です。アプリ、アプリで使用している他の SDK と unisizeSDK で複数項目になる場合は、必要な項目をすべて追加して下さい。

## unisizeSDK で使用する Required Reason API（v3.0 以降）

**unisizeSDK v3.0 以降を導入する場合は、以下の項目の追加が必須です。**

v3.0 で beid（unisize がユーザーを識別するために発行するユニークな ID）を SDK 内で保持するようになり、その保存先として `UserDefaults` を使用しています。`UserDefaults` は Apple が定める Required Reason API（理由の記載が必要な API）に該当するため、アプリのプライバシーマニフェストファイルへ使用理由の記載が必要です。

**App Privacy Configuration > Privacy Accessed API Types > Item ◯**
```
Privacy Accessed API Type：NSPrivacyAccessedAPICategoryUserDefaults
Privacy Accessed API Reasons > item 0：CA92.1
```

PrivacyInfo.xcprivacy をソースコードとして直接編集される場合は、以下の記述になります。

```xml
<key>NSPrivacyAccessedAPITypes</key>
<array>
    <dict>
        <key>NSPrivacyAccessedAPIType</key>
        <string>NSPrivacyAccessedAPICategoryUserDefaults</string>
        <key>NSPrivacyAccessedAPITypeReasons</key>
        <array>
            <string>CA92.1</string>
        </array>
    </dict>
</array>
```

理由コード `CA92.1` は「アプリ自身（または同一 App Group 内のアプリ）からのみアクセスできる情報の読み書きに使用する」ことを示すものです。unisizeSDK が `UserDefaults` へ保存するのは beid とその引き継ぎ状態のみで、いずれもアプリの外部へ共有したり、トラッキングの目的で使用したりすることはありません。

### aunn コーディネート機能を使用しない場合も対応が必要です

**aunn コーディネート機能を使用せず、unisize バナー・CV タグのみをご利用の場合も、本項目の追加が必要です。** v3.0 では unisize バナーの読み込み完了時に SDK が beid の保存領域を参照するため、aunn の実装有無にかかわらず `UserDefaults` へのアクセスが発生します。

そのため、**v2.x から v3.0 へアップデートされる既存のアプリでも、プライバシーマニフェストファイルへの追記が必要になります。** v2.x では `UserDefaults` を使用していなかったため、これまで本項目を記載されていないアプリが対象です。

### 対応漏れの際に発生する事象について

unisizeSDK はプライバシーマニフェストファイル（PrivacyInfo.xcprivacy）を同梱していないため、本項目はアプリ側のプライバシーマニフェストファイルへ記載していただく必要があります。

記載のないまま App Store Connect へアプリを提出された場合、Apple より `ITMS-91053: Missing API declaration` の警告メールが届きます。今後 Apple の運用が変更された際には、提出そのものが受け付けられなくなる可能性がありますので、v3.0 へアップデートされる際は必ずご対応ください。
